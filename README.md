A machine-learning based application that classifies text messages as **Spam** or **Not Spam**.

## 🚀 Features

- 📩 Classifies messages as Spam or Not Spam
- 🤖 Machine Learning based prediction
- 🧹 Text preprocessing
- 📊 Dataset-based model training
- ⚡ Fast predictions
- 🐍 Built with Python
